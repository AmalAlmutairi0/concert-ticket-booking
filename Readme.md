Night Under the Stars — Concert Ticket Booking Page

A single-page concert ticket booking design built with pure HTML and CSS, featuring event details, artist lineup, and ticket tiers.

Tech Stack
- HTML5 — semantic structure
- CSS3
  - Flexbox — header, footer, and card content alignment
  - Grid — details section, lineup cards, ticket tiers
  - Position — floating badge, sticky footer

  ![Night Under the Stars preview](screenshot.png)

 Features
  - Responsive card layouts for event details and ticket types
  - Sticky footer that anchors to the bottom of the viewport
  - Custom color palette and typography (Playfair Display + Cairo)
